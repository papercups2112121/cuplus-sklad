💰 PDF для бухгалтерії

Ціна за тону — довідково-аналітична, для КОЖНОЇ позиції своя. Ніде не зберігається як частина ордера/складу — вводиться заново під кожен звіт (можна ставити нову щоразу).

"Зберегти" — лише запам'ятовує введене на потім (без друку). Щоб відредагувати пізніше — знову натисніть "💰 PDF для бухгалтерії", форма підставить збережене.

💰 Вартість позиції

Кількість на складі НЕ змінюється — це лише запис вартості для звіту бухгалтерії (аркуш "Звіти" → "Звіт по приходу сировини").

✏️ Редагувати надходження
Ця частина буде віднята з полів вище і збережена окремою позицією надходження — з власним кольором.
✏️ Редагувати запис надходження

Тип/розмір/кількість/вага цього запису НЕ змінюються — лише довідкові поля для звіту бухгалтерії.

✏️ Редагувати партію

🔁 Швидко: одна ціна на всі позиції

Одиниця (кг/т/м²/шт) підбирається окремо для кожної позиції — тут вписуєш число, воно підставиться як "ціна за одиницю" в кожен рядок нижче. Окремі позиції можна далі поправити вручну.

➕ Запис вручну (для обліку)

Для сировини, яку вже перероблено і на складі окремо її нема — лише запис у журналі для звіту бухгалтерії, кількість на складі НЕ змінюється.

🏭 Станки (продуктивність)
▸

Один станок може робити КІЛЬКА продуктів (змінний комплект молд — напр. один станок робить і "300мл ДВ", і "300мл Гофро"). Вкажи всі розмір+тип, які цей станок здатен робити, плюс к-сть змін на місяць саме для нього і продуктивність шт/зміну — використовується в "Плануванні" для перевірки, чи не перевищує план реальну можливість станка.

🧩 Кліше — розклад по розмір/тип
▸

Одне кліше часто йде на кілька розмірів/типів стакана одразу, і на кожному — своя к-сть заготовок на листі. Тут для кожної комбінації (кліше + розмір + тип) розписуєш точно, скільки і яких малюнків на листі — і "В роботу" підставлятиме цей розклад автоматично, без вгадування за назвою.

📋 Ревізія — вся сировина по товарах

Один товар — один рядок, всі форми сировини разом (рулон/аркуші, заготовки висічені, ящики треба клеїти, ящики готові) — щоб під час фізичної ревізії не гортати різні картки складу, а порахувати все одразу.

📥 Імпорт звіту зміни (з «Закриття зміни»)

Завантажте PDF-звіт із «Закриття зміни» (за день, тиждень чи будь-який період) — застосунок сам розпізнає позиції, порахує реальну витрату сировини і зіставить факт із планом.
